Analisis data penjualan selama musim Diwali menggunakan alur kerja lengkap: pembersihan data dengan SQL, eksplorasi dengan Python, dan visualisasi dengan Excel serta Power BI.

## 📌 Ringkasan Proyek

Proyek ini menganalisis perilaku pembelian pelanggan selama Diwali untuk membantu bisnis memahami segmen pembeli dan kategori produk yang paling berkontribusi terhadap penjualan.

## 🎯 Tujuan

- Membersihkan data mentah penjualan menggunakan SQL.
- Mengeksplorasi pola pembelian dengan Python.
- Membangun dashboard interaktif di Excel dan Power BI.
- Menghasilkan insight untuk strategi penjualan musim festival berikutnya.

## 🔄 Alur Kerja

```
Data mentah (CSV) → Cleaning (SQL) → EDA (Python) → Dashboard (Excel & Power BI)
```

## 🛠️ Tools

- **SQL** untuk data cleaning
- **Python (Jupyter Notebook)** untuk analisis eksploratif
- **Microsoft Excel** untuk dashboard
- **Power BI** untuk dashboard interaktif

## 📁 Struktur Repository

```
Diwali-sales-analyst/
├── Diwali Sales Data.csv                        # Dataset
├── Diwali Sales SQL Data Cleaning.sql           # Script pembersihan data
├── Diwali sales analyst.ipynb                   # Analisis Python
├── Diwali Sales Data Dashboard.xlsx             # Dashboard Excel
├── Diwali Sales Analysis PowerBI Dashboard.pbix # Dashboard Power BI
└── README.md
```

## 🚀 Cara Menggunakan

1. Clone repository:
   ```bash
   git clone https://github.com/achmadhavid/Diwali-sales-analyst.git
   ```
2. Jalankan `Diwali Sales SQL Data Cleaning.sql` pada data untuk melihat proses cleaning.
3. Buka `Diwali sales analyst.ipynb` dengan Jupyter Notebook.
4. Buka `.xlsx` dengan Excel dan `.pbix` dengan Power BI Desktop untuk melihat dashboard.
